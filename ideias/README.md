## Como registrar uma ideia nova

1. Crie ou edite um arquivo `AAAA-MM-tema.md` nesta pasta.
2. Formato mínimo: **Ideia · Dor que resolve · Evidência/benchmark · Esforço (B/M/A) · Impacto (B/M/A) · Status** (registrada → aprovada → em produto → arquivada com motivo).
3. Atualize a tabela acima.
4. Nunca apague uma ideia: se for descartada, marque "arquivada" e escreva o porquê.
